# Church & Trellis – public website

This repository publishes **churchandtrellis.com**.

Don't edit the website here. It is written in the app's repository,
[pian1966/church-hub](https://github.com/pian1966/church-hub), in the `site` folder.
A robot (`.github/workflows/publish.yml`) copies it from there every day and publishes it.
To publish a change straight away: **Actions → Publish website → Run workflow**.

The app itself is at https://app.churchandtrellis.com/
